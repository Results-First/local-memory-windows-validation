# Local Memory Windows validation

Test infrastructure only. No public application download or application source is provided here.
The workflow tests a SHA256-pinned evaluation ZIP attached to an unpublished draft release on fresh standard GitHub Windows runners. Only synthetic audio is used. No dependencies are installed for the app.

Receipts are printed in workflow logs, without artifact/cache storage. A pass proves execution on a separate hosted Windows Server image, not Windows 11 consumer compatibility, native dialogs or audible playback.
